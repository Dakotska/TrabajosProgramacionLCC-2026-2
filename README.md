## 🚀 Cómo Ejecutar los Proyectos

1. **Clonar este repositorio:**
   ```bash
   git clone https://github.com/Dakotska/tu-repositorio.git
   ```

2. **Ejecutar proyectos de PSeInt:**
   - Abre [PSeInt](http://pseint.sourceforge.net/).
   - Importa o abre cualquier archivo `.psc` guardado en la carpeta del semestre correspondiente.

3. **Ejecutar scripts de Python:**
   ```bash
   python3 nombre_del_archivo.py
   ```
